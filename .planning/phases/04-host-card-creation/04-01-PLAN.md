**CardService actor:**
- Import Foundation and Supabase
- Define `CardError` enum (LocalizedError, Sendable) with cases: createFailed(String), fetchFailed(String), updateFailed(String), clipCreateFailed(String)
- Create `public actor CardService` with empty init

**Methods:**
1. `createCard(title: String, recipientName: String, occasion: String?, hostId: UUID) async throws -> Card`
   - Create NewCard with shareToken = UUID().uuidString.lowercased()
   - Insert into "cards" table using supabase.from("cards").insert(newCard).select().single().execute().value
   - Return the created Card
   - Wrap errors in CardError.createFailed

2. `createClip(cardId: UUID, participantId: UUID, videoUrl: String, durationSeconds: Decimal?, orderPosition: Int, status: String = "uploaded") async throws -> Clip`
   - Create NewClip with provided values
   - Insert into "clips" table using same pattern
   - Return the created Clip
   - Wrap errors in CardError.clipCreateFailed

3. `fetchCardsForHost(hostId: UUID) async throws -> [Card]`
   - Select from "cards" where host_id = hostId
   - Order by created_at descending
   - Return array of Cards
   - Wrap errors in CardError.fetchFailed

4. `updateCardStatus(cardId: UUID, status: String) async throws`
   - Update "cards" table set status where id = cardId
   - Wrap errors in CardError.updateFailed

Follow the StorageService pattern for actor isolation and error handling.
