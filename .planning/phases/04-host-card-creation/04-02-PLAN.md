Create TOY/Features/CardCreation/ directory and CreateCardViewModel.swift:

**CreateCardViewModel:**
- Import Foundation, SwiftUI, TOYShared
- Use @Observable macro (iOS 17+ pattern, app targets 18.2+)
- Use @MainActor for UI state management

**Properties:**
- `var title: String = ""`
- `var recipientName: String = ""`
- `var occasion: String? = nil` (for future use, not required in form)
- `var isCreating: Bool = false`
- `var errorMessage: String? = nil`
- `var createdCard: Card? = nil`

**Computed Properties:**
- `var isFormValid: Bool` - returns true if title and recipientName are non-empty after trimming whitespace
- `var canSubmit: Bool` - returns isFormValid && !isCreating

**Dependencies:**
- `private let cardService = CardService()`

**Methods:**
- `func createCard(hostId: UUID) async`
  - Guard canSubmit, else return
  - Set isCreating = true, errorMessage = nil
  - Call cardService.createCard with trimmed title, trimmed recipientName, occasion, hostId
  - On success: set createdCard = result
  - On failure: set errorMessage = error.localizedDescription
  - Always: set isCreating = false

- `func reset()`
  - Clear all fields to defaults
  - Set createdCard = nil, errorMessage = nil

The createdCard property will be used by the parent view to detect when card creation is complete and navigate to recording.
