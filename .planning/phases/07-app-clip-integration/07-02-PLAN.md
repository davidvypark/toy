  <files>
    TOYClip/TOYClip.entitlements

  <action>
Create the TOYClip directory and files manually (Xcode will integrate them):

1. Create directory: `mkdir -p TOYClip`

2. Create TOYClip/TOYClip.entitlements:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>com.apple.developer.associated-domains</key>
    <array>
        <string>appclips:toy.app</string>
    </array>
    <key>com.apple.developer.parent-application-identifiers</key>
    <array>
        <string>$(AppIdentifierPrefix)com.toy.TOY</string>
    </array>
</dict>
</plist>
```

3. Create TOYClip/Info.plist:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>NSAppClip</key>
    <dict>
        <key>NSAppClipRequestEphemeralUserNotification</key>
        <false/>
        <key>NSAppClipRequestLocationConfirmation</key>
        <false/>
    </dict>
    <key>UILaunchScreen</key>
    <dict/>
    <key>NSCameraUsageDescription</key>
    <string>TOY needs camera access to record your video message</string>
    <key>NSMicrophoneUsageDescription</key>
    <string>TOY needs microphone access to record audio with your video</string>
</dict>
</plist>
```

The entitlements specify:
- `appclips:toy.app` - The domain for App Clip invocation (note: appclips: not applinks:)
- `parent-application-identifiers` - Links to main app for keychain sharing and App Store overlay

The Info.plist includes:
- `NSAppClip` dictionary (required for App Clips)
- Camera/microphone privacy descriptions (required for recording)
- Launch screen configuration

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Add App Clip target in Xcode</name>
  <action>
The user must manually add the App Clip target in Xcode because:
1. Xcode's project.pbxproj is complex and brittle
2. App Clip targets have specific build settings that Xcode templates configure correctly
3. Target dependencies and signing require Xcode UI

User instructions:

1. Open TOY.xcodeproj in Xcode
2. File > New > Target
3. Search for "App Clip" and select it
4. Configure:
   - Product Name: TOYClip
   - Bundle Identifier: com.toy.TOY.Clip (MUST be main app ID + .Clip)
   - Language: Swift
   - User Interface: SwiftUI
   - Embed in Application: TOY
5. Click Finish
6. When prompted about activating the scheme, click "Activate"

After target creation:
7. Select TOYClip target > Build Settings
8. Search "Code Signing Entitlements" and set to: TOYClip/TOYClip.entitlements
9. Select TOYClip target > General > Frameworks, Libraries, and Embedded Content
10. Click + and add TOYShared (from your project, not external)

Verify in Xcode:
- TOYClip target appears under Targets
- TOYClip scheme is available
- Build Settings show correct entitlements path
- TOYShared appears in linked frameworks
  </action>

After completing the above:
1. Select TOYClip scheme in Xcode
2. Build (Cmd+B) - should succeed (may have placeholder ContentView)
3. Verify bundle ID in target General settings shows com.toy.TOY.Clip
