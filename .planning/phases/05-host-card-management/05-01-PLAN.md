   - Return array of Clip models
   - Throw `CardError.fetchFailed` on error

   - First, delete from storage bucket "clips" using `supabase.storage.from("clips").remove(paths: [storagePath])`
   - Catch storage errors but continue (file may already be deleted)
   - Then delete from database using `.delete().eq("id", value: clipId)`
   - Throw `CardError.updateFailed` if database delete fails

Also add a new error case to CardError:
- `case deleteFailed(String)` with appropriate error description
