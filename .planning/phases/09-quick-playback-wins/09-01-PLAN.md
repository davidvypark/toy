  <action>
In PublishedCardPlayerView.swift, find the `loadVideo()` method. Inside the `await MainActor.run` block, after the line:
```swift
let avPlayer = AVPlayer(playerItem: playerItem)
```
Add this line immediately after:
```swift
avPlayer.automaticallyWaitsToMinimizeStalling = false
```

This tells AVPlayer to start playback as soon as any buffered data is available, rather than waiting for enough data to guarantee stall-free playback. For 7-second clips (2-5MB), the default wait behavior causes 1-3 second delays that are unnecessary.

IMPORTANT: Do NOT change MontagePreviewView.swift -- it intentionally sets `automaticallyWaitsToMinimizeStalling = true` (line 354) because the queue player benefits from buffering ahead to prevent black flashes between clips. Do NOT change ClipPreviewSheet.swift -- it already sets `automaticallyWaitsToMinimizeStalling = false` (line 181). Do NOT change VideoPreviewView.swift -- it plays from local files where buffering is irrelevant.

Do NOT add stall recovery observers preemptively. For 7-second clips on any reasonable connection, stalling is extremely unlikely.
  </action>

Build the project with `xcodebuild build -scheme TOY -destination 'platform=iOS Simulator,name=iPhone 16' -quiet 2>&1 | tail -5` and confirm no errors. Grep to confirm the property is set: `grep -n "automaticallyWaitsToMinimizeStalling" TOY/Features/PublishedCard/PublishedCardPlayerView.swift` should show the new line with `= false`.
  </verify>
  <done>
