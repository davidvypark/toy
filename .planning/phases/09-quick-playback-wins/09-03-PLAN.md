<objective>
Replace the manual NotificationCenter + seek-to-zero looping pattern with AVPlayerLooper across all three looping player views for seamless, gap-free video looping.

Purpose: The current pattern of observing AVPlayerItemDidPlayToEndTime, then seeking to zero and calling play(), causes a visible 100-300ms gap (black flash or frozen frame) at the loop point. AVPlayerLooper pre-buffers the loop transition internally, eliminating the visible gap entirely.
Output: Modified PublishedCardPlayerView.swift, ClipPreviewSheet.swift, and VideoPreviewView.swift using AVQueuePlayer + AVPlayerLooper for seamless looping.
</objective>

2. Replace the `setupPlayer(with:)` method. The current code creates an AVPlayer, sets autoWait to false, plays, adds a status observer, and adds a NotificationCenter looping observer. Replace with:
```swift
private func setupPlayer(with url: URL) {
    let playerItem = AVPlayerItem(url: url)
    let queuePlayer = AVQueuePlayer()
    queuePlayer.automaticallyWaitsToMinimizeStalling = false

    // AVPlayerLooper handles seamless looping internally
    let looper = AVPlayerLooper(player: queuePlayer, templateItem: playerItem)

    // Status observer on the template item
    playerStatusObserver = playerItem.observe(\.status, options: [.new]) { item, _ in
        DispatchQueue.main.async {
            if case .failed = item.status {
                loadError = item.error?.localizedDescription ?? "Failed to load video"
            }
        }
    }

    queuePlayer.play()

    player = queuePlayer
    playerLooper = looper
}
```

    player?.replaceCurrentItem(with: nil)
