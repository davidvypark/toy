     - Tiers at or above the clip count are tappable and selectable
  4. Bottom CTA area (pinned, not in ScrollView):
     - TOYButton.primary with title "Publish -- \(priceString)" where priceString is the localized price for the selected tier

     - Disabled when `isPurchasing` or `isLoading`
  5. Toolbar: "Cancel" button on leading that calls `onCancel()` then `dismiss()`

  **Purchase flow (on CTA tap):**
  ```swift
  func handlePurchase() async {
      guard let identifier = selectedTier.packageIdentifier,
            let package = packages[identifier] else { return }

      isPurchasing = true
      errorMessage = nil

      do {
          // Step 1: Execute purchase via RevenueCat
          let (_, transactionId) = try await PurchaseService.shared.purchaseWithTransaction(package: package)

          // Step 2: Record purchase to Supabase IMMEDIATELY (before publish)
          let cardService = CardService()
          try await cardService.recordTierPurchase(
              cardId: card.id,
              maxParticipants: selectedTier.maxParticipantsValue,
              transactionId: transactionId ?? "unknown"
          )

          // Step 3: Dismiss and trigger publish
          await MainActor.run {
              dismiss()
              onPurchaseComplete()
          }
      } catch let error as PurchaseError where error == .purchaseCancelled {
          // User cancelled Apple payment sheet -- do nothing, stay on checkout
          isPurchasing = false
      } catch {
          errorMessage = error.localizedDescription
          isPurchasing = false
      }
  }
  ```

  Note on PurchaseError comparison: `PurchaseError` is an enum. For the cancellation check, use a pattern match: `catch is PurchaseError` won't work cleanly. Instead use:
  ```swift
  } catch {
      if case PurchaseError.purchaseCancelled = error {
          isPurchasing = false
          return
      }
      errorMessage = error.localizedDescription
      isPurchasing = false
  }
  ```

  **Price loading:** Use the same pattern as TierSelectionSheet:

  private func loadPrices() async {
      do {
          packages = try await PurchaseService.shared.fetchTierPackages()
      } catch {
          errorMessage = "Unable to load prices"

      isLoading = false
  }
  ```

  Call in `.task { await loadPrices() }`.

  **Price helper:**

  private func priceString(for tier: CardTier) -> String? {
      guard let identifier = tier.packageIdentifier,
            let package = packages[identifier] else { return nil }
      return package.localizedPriceString
  }
  ```

  **CRITICAL: Correct tier gate logic (grandfathering-safe).**

  Do NOT use `cardViewModel?.needsUpgradeToPublish(for: card)` for the gate. That method compares CardTier enums, which breaks grandfathered cards. A card with `maxParticipants=8` and 7 clips would incorrectly trigger the gate because `CardTier.requiredTier(for: 7)` returns `.starter` while `CardTier.fromMaxParticipants(8)` returns `.free`.

  Instead, use a DIRECT comparison against `card.maxParticipants`:
  ```swift
  /// Whether this publish attempt needs a tier upgrade.
  /// Uses card.maxParticipants directly (not CardTier comparison) to respect grandfathered cards.
  private var needsUpgrade: Bool {
      sortedClips.count > card.maxParticipants
  }
  ```

  This correctly handles:
  - New free card (maxParticipants=5) with 3 clips: 3 > 5 = false (publishes free)
  - New free card (maxParticipants=5) with 7 clips: 7 > 5 = true (shows checkout)
  - Grandfathered card (maxParticipants=8) with 7 clips: 7 > 8 = false (publishes free, correctly grandfathered)
  - Already-purchased card (maxParticipants=25) with 12 clips: 12 > 25 = false (publishes without re-purchase)

  **Modify `actionButtons`** (currently at line 278-294):

  Replace the current action closure of TOYButton.primary:
  ```swift
  @ViewBuilder
  private var actionButtons: some View {
      VStack(spacing: TOYSpacing.md) {
          TOYButton.primary(
              publishViewModel.state.isInProgress ? "Publishing..." : "Publish Card",
              isLoading: publishViewModel.state.isInProgress
          ) {
              if !hasPurchased && needsUpgrade {
                  showCheckout = true
              } else {
                  Task {
                      await publishViewModel.publishWithStitching(
                          card: card,
                          clips: sortedClips
                      )
                  }
              }
          }
          .disabled(isLoadingURLs || publishViewModel.state.isInProgress)
      }
  }
  ```

  Key detail: `!hasPurchased && needsUpgrade` -- if `hasPurchased` is true (purchase succeeded in this session), skip the gate even though the local `card` struct is stale. This satisfies PURCH-03 (retry without re-purchasing).
